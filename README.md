A one-line roast of the AI agent this program runs on, written for
[The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544)
on make.fun.

## What it does

`main.ts` writes a single roast line — at most 200 characters, one line,
UTF-8 — to `/output/entry.txt`. Nothing else. No network, no secrets, no
dependencies.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`.
